# Experts Associates — Website V3

Professional static website for Experts Associates and its CoreAxis ERP / CoreAxis HRMS brands.

## Files
- `index.html` — complete homepage
- `style.css` — responsive design and animations
- `script.js` — mobile navigation, reveal animations and enquiry mailto workflow
- `robots.txt` / `sitemap.xml` — basic SEO files
- `CNAME` — GitHub Pages custom domain
- `assets/` — user-supplied Experts Associates, CoreAxis ERP and CoreAxis HRMS logos

## Publish on GitHub Pages
1. Upload all files to the root of the `main` branch.
2. Keep the three logo PNGs inside `assets/`.
3. In GitHub: Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. The custom domain should be `www.expertsassociate.com`.
5. Confirm DNS at your domain provider points the domain to GitHub Pages according to GitHub's current instructions.

## Before launch
- Verify the phone and email details.
- Add Privacy Policy and Terms pages if required.
- Replace any future factual claims with verified figures.
- For stored lead capture, connect the form to a backend/CRM rather than relying on `mailto:`.
